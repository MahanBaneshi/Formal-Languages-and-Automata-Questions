# Theory of Languages and Automata – Practice Materials

This repository contains a collection of **practice questions, quizzes, and their official solutions** for the **Theory of Languages and Automata** course offered by the **Department of Computer Engineering, Shahid Beheshti University** during the **Fall 2025** and **Spring 2026** semesters.

The purpose of this repository is to provide students with organized study materials to help them prepare for quizzes, midterm exams, and final examinations.
